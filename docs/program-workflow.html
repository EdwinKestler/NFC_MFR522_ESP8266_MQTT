Every branch returns to IDLE. MQTT reconnect resumes a pending TX_CARD publish if a tag was waiting.

Inbound MQTT (callback, not a state)

mqtt5_client onMessage
PARSE → QUEUE WORK
mqtt5nanoParse.cpp parse PUBLISH slices.h topic/payload slices ArduinoJson deserializeJson src/main.cpp handleAlarmJson src/settings.h response/reboot/update topics
Callback stays short: copy CHIPID + ALARM_STATE, or set rebootRequested_. LED/buzzer run later in IDLE via Feedback (direct GPIO in main.cpp, not BlinkRGB).
Color chips on each card are the exact files/libraries used in that step. BlinkRGB remains in the tree but is not linked by the V1.4a firmware.
